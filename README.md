# Chess Multiplayer

## Aviso 

Esse é um projeto de estudo com o objetivo de desenvolver o meu conhecimento na unity, com foco na parte do multiplayer. 
A ideia foi fazer um jogo de xadrez totalmente baseado tanto nas mecânicas quanto na parte visual do site mais famoso do mundo de xadrez online, <a href="https://chess.com/" target="_blank">chess.com</a>.
A maioria dos assets desse jogo foram adquiridos no próprio site do jogo <a href="https://chess.com/" target="_blank">chess.com</a>.

Download do jogo: <a href="https://igorsantos.itch.io/chess-multiplayer" target="_blank">itch.io</a>
